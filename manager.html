Il Mio Mondo

Dashboard

La vista d'insieme di tutti i tuoi progetti. Ogni progetto ha un semaforo che ti dice al volo lo stato: verde (tutto OK), giallo (qualcosa da controllare), rosso (errore), grigio (fermo). Card con accesso rapido a cartella, terminale, VS Code e browser.

Semafori Health Bar Quick Stats One-Click
🔌

Porte

Port Monitor

“Chi usa cosa” in linguaggio umano. Vedi tutte le porte attive sul tuo Mac con il nome del progetto, il processo e il PID. Puoi chiudere una porta bloccata con un click, copiare l'URL o aprirla direttamente nel browser.

Ricerca Kill Process Apri Browser Copia URL
🐳

Docker

Docker Monitor

Container raggruppati per progetto Compose. Avvia, ferma o riavvia un singolo container o un intero progetto. Viewer log inline per debugging e metriche CPU/RAM in tempo reale per ogni container.

Per Progetto Log Viewer CPU/RAM Start/Stop
🧠

Consulente

Smart Advisor AI

Un consulente AI locale powered by Ollama. Analizza i tuoi progetti e ti dà suggerimenti in linguaggio naturale. Routing multi-modello automatico: triage rapido con mistral-small, analisi con qwen3, ragionamento profondo con deepseek-r1.

Multi-Model 100% Locale Ollama Auto-Routing
🧪

Test UI

UI Test Agent

Health check automatici per i tuoi progetti web. Verifica raggiungibilità, tempo di risposta, content type, sicurezza HTTPS e pattern di errore nella pagina. Test singolo, per progetto o tutti in un click.

Health Check HTTPS Error Detection Response Time
🧠

MNEMO

Context Multiplier

Dashboard per monitorare MNEMO, il proxy che moltiplica il contesto di Ollama. Visualizza lo stato della connessione, le metriche di utilizzo e la gestione della memoria contestuale per le tue sessioni AI.

Proxy Monitor Context Metriche
🦞

LobsterCode

Coding Assistant integrato

L'agente AI di coding Lobster Code, integrato direttamente nell'app. Modifica file, gestisce git, traccia le modifiche — tutto senza uscire da Lobster Manager. La potenza di un coding agent dentro il tuo cockpit.

Agent AI Git File Ops Tracking
