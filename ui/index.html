Come usarlo

Dalla riga di comando al progetto completo

Non è solo un chatbot. È un collega silenzioso che esegue, non chiacchiera.

🏗️

Scaffolding progetti

Crea strutture complete: React, Flask, FastAPI, static site. Configura linting, testing, CI/CD in un comando.

→ "Crea un'API REST in FastAPI con autenticazione JWT e database SQLite"
🐛

Debug e fix

Legge il codice, trova il bug, lo corregge e verifica che funzioni. Senza che tu debba alzare un dito.

→ "Il login non funziona, controlla auth.py e fixalo"
📊

Analisi dati

Elabora CSV, genera grafici con matplotlib, calcola statistiche. Tutto in locale, i tuoi dati restano tuoi.

→ "Analizza vendite.csv, mostra trend mensile e top 5 prodotti"
🔧

DevOps locale

Gestisci Docker, configura nginx, scrivi Dockerfile. Automatizza task ripetitivi con script bash.

→ "Scrivi un Dockerfile multi-stage per la mia app Node.js"
📝

Documentazione

Genera README, docstring, JSDoc, commenti. Legge il codice e produce documentazione coerente.

→ "Aggiungi docstring a tutte le funzioni in utils/"
🎨

Frontend da zero

HTML, CSS, JavaScript — componenti, animazioni, layout responsive. Crea e ti mostra il risultato live.

→ "Crea una landing page per il mio portfolio con dark mode"
